# 不做本地离线口令穷举

## 口令：只禁「穷举式离线破解」

- ❌ 禁的是**穷举**：任何批量/自动化的口令空间搜索——hashcat / John / 彩虹表、
  字典文件、掩码/规则自动生成候选组合，一律不跑。
- ❌ 穷举对象包括但不限于：/etc/shadow、NTLM/NTDS、Kerberoasting 提取的 TGS、
  JWT HS256 签名密钥、SSH 私钥 passphrase、ZIP/RAR/openssl 加密文件口令、
  数据库导出的口令哈希、WPA 握手包。
- ✅ **点名弱口令比对不算穷举**：对拿到的哈希/密文验证具体猜想——"这个 bcrypt 是不是
  admin？""JWT secret 是不是 123456 / jwt_secret？""压缩包是不是厂商默认口令？"——
  逐个手工计算比对，允许做。判断标准：口令是具体点名的、逐个算的 → 允许；
  引入字典文件、掩码或自动生成候选 → 即为穷举，禁止。
- ✅ 拿到哈希/密文本身即可登记 finding；还原明文不是必须（如需确认，做上一条的点名验证）。
- ✅ 在线登录的弱口令/默认口令尝试不受本技能限制，照常做（速率与破坏性按平台默认口径，本技能不额外设限）。
- 💡 提示（非强制）：凭据优先靠找——泄露的 .env / API key / 默认口令，拿到直接在线验证。
