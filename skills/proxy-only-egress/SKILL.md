# 出站只走代理，严禁直连

## 出站：全部连接走平台配置的代理，严禁直连

平台已把 shell 环境的 HTTP_PROXY / HTTPS_PROXY / ALL_PROXY 注入指向平台代理，平台 HTTP 工具也
强制走代理。默认就是代理出口，因此要求只有一条——不绕过：

- ❌ 不得以任何方式绕开：不 unset/清空这些变量，不用 --noproxy / NO_PROXY，不写原生 socket 直连。
- ⚠️ 不读环境变量的工具（nmap SYN 扫描、nc/zmap、原生 socket 等）必须显式套代理
  （proxychains 或工具自带代理参数）；套不上的就不跑，改用被动源或平台 HTTP 工具。
- ❌ 代理不通/超时：停下并在结果中报告「代理不可用」，严禁降级为直连重试。
- 域名解析交给代理（HTTP CONNECT 由代理端解析），不做绕过代理的独立 DNS / 端口探测。
